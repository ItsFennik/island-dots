# FAQ

### Is Island a compositor?

No. It is a Quickshell shell that runs on Hyprland, niri, Sway/SwayFX/Scroll, MangoWC and other layer-shell compositors.

### Does it need systemd?

No. The compositor starts `scripts/island-startup`, which handles dbus, XDG_RUNTIME_DIR, PipeWire and the session helpers. A systemd user unit is optional. See [non-systemd.md](non-systemd.md).

### Does it replace my bar, launcher, notification daemon and lock screen?

Yes. The bar, Spotlight, Launchpad, Notification Centre, Control Centre and lock screen are part of the same Quickshell process. Remove waybar, dunst/mako/swaync and other bars to avoid duplicate surfaces and notification owners.

### Can I use it on GNOME or KDE?

Not as a shell. It needs layer-shell, foreign-toplevel and ext-session-lock. Several GNOME/KDE surfaces are not exposed through those protocols.

### Where are my settings?

`~/.config/island/settings.json`. Only values that differ from `defaults.json` are stored. Change them in Settings when possible. Compositor files headed `Generated by` are overwritten.

### How do I add a colour scheme?

Copy a file in `themes/`, change the colours, keep the file name lower-case, and pick it in Settings. See [theming.md](theming.md).

### Why is my wallpaper not restored at login?

`island-startup` calls `wallpaper-set.sh --restore`. Check that `awww` or `swww` is installed and that `~/.local/state/island/wallpaper` points to a file that still exists.

### Why does Settings show a blank page after an update?

A hot reload caught Settings while the Compositor singleton was loading. Run `qs -c island ipc call shell reload`; if that does not fix it, restart the shell with `qs -c island kill` and `scripts/island-startup`.

### Can I use hyprlock instead of the built-in locker?

Yes. Settings > Desktop & Widgets > Lock Screen > Locker. `apply-theme.sh` generates `~/.config/hypr/hyprlock.conf`.

### Does Island theme apps outside the repository?

Yes, when those apps and config directories exist. `apply-theme.sh` covers GTK 3/4, Kvantum, kitty, Foot, btop, cava, Vesktop, Herdr, VSCodium, Steam, Brave/Helium/Chromium, LibreWolf/Sidebery and running Neovim instances. Terminal and editor configs themselves are not shipped.

### How do I update?

```sh
cd ~/.config/quickshell/island
git pull
./apply-theme.sh --restore
./apply-settings.sh
```

If the shell is running, hot reload normally picks up QML changes. New fonts or a broken reload need `qs -c island kill` followed by `scripts/island-startup`.

### Why is there no Discord/Spotify integration?

Island uses standard MPRIS for now playing and standard desktop entries for apps. App-specific integrations are outside the scope of this repository.
