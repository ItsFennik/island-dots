# Compositor glue

`services/Compositor.qml` is the only place that knows which compositor is running. It exposes the focused screen, workspaces, window actions, overview actions, logout and lock.

Supported detection:

- Hyprland: `HYPRLAND_INSTANCE_SIGNATURE`, `Quickshell.Hyprland`
- niri: `NIRI_SOCKET`, `niri msg -j event-stream`
- Sway, Scroll, i3: `SWAYSOCK` or `I3SOCK`, `swaymsg` / `scrollmsg`
- MangoWC: `XDG_CURRENT_DESKTOP` contains `mango`, `mmsg watch all-monitors`

The glue files are in `examples/`:

- `examples/hyprland/island.lua`: exec, keybinds, blur and animation layer rules
- `examples/niri/island.kdl`: startup, keybinds, includes
- `examples/sway/island.conf`: startup, keybinds, includes
- `examples/mango/island.conf`: startup, keybinds

Generated compositor files come from `apply-settings.sh` and `apply-theme.sh`. Do not hand-edit files with a `Generated by` header.

Other compositors with layer-shell, foreign-toplevel and ext-session-lock get the shell and lock screen. Window menu items that need a compositor API are disabled or fall back to foreign-toplevel.
